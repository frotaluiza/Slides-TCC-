\begin{slide}{Comentários Finais}
  \footnotesize
  \begin{columns}
    \begin{column}{0.94\linewidth}
    \begin{Item}[0.10]
    \item As redes neurais híbridas (PhyResidual) se destacaram com as melhores performances em Test RMSE para duas das três variáveis (Flux e T$_{ref}$), com redução de até 73,8\% sobre o modelo 0D.
    \item A arquitetura residual atua como \textbf{corretor de viés} do modelo físico 0D: aprende a discrepância entre as predições físicas e os dados, preservando o comportamento físico onde ele está correto.
    \item O contraste Test vs CV revela que modelos lineares (Ridge, OLS) têm melhor capacidade de extrapolação para as temperaturas, enquanto o PhyResidual é superior no Flux.
    \item A seleção por RMSE de cada variável não garantiu o melhor modelo para aquela variável — apenas para o Flux o modelo otimizado para a variável foi o vencedor, sugerindo que múltiplos critérios são necessários.
    \end{Item}
    \end{column}
  \end{columns}
  \note{Comentários finais: híbridos melhores no Test; PhyResidual como corretor de viés; contraste Test vs CV; seleção por target não garante melhor modelo. [~2 min]}
