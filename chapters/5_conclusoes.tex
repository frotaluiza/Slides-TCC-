\begin{slide}{Hibridização e Generalização}
  \footnotesize
  \begin{columns}
    \begin{column}{0.94\linewidth}
    \begin{Item}[0.10]
    \item A busca de hiperparâmetros guiada pelo RMSE de cada variável não garantiu que o modelo otimizado para uma variável fosse o melhor para aquela variável: para T$_{alim}$, a Baseline Flux (otimizada para o Flux, 0,178) superou a Baseline Alim (otimizada para T$_{alim}$, 0,215); para T$_{ref}$, o PhyResidual (base Flux, 0,214) superou o PhyResidual Ref (otimizado para T$_{ref}$, 0,231). Apenas para o Flux o modelo otimizado para a variável foi o vencedor.
    \item A arquitetura residual PhyResidual atua como \textbf{corretor de viés}: aprende a discrepância entre o modelo 0D e os dados reais, preservando a física onde está correta. Esse papel foi bem-sucedido para o fluxo de permeado (RMSE de 0,206 para 0,054, R$^2$ 0,979) e para T$_{ref}$ (0,214), comprovando a eficácia da hibridização nessas variáveis.
    \item T$_{alim}$ foi a única variável onde o PhyResidual não foi o melhor modelo — a Baseline Flux (Stage 1), puramente \textit{data-driven}, o superou (0,178 vs 0,183). Esse resultado é coerente com a pior performance do modelo 0D para T$_{alim}$ (R$^2$ de $-0{,}404$), que tornou a correção residual menos eficaz quando a referência física tinha baixa qualidade.
    \item Adicionalmente, o PhyResidual (Flux) manteve erro estável na CV para o Flux (0,072 contra 0,082 do Lasso\_Indep). Para as temperaturas, observa-se contraste entre Test e CV: embora o PhyResidual tenha liderado no Test para T$_{ref}$ (0,214 vs 0,219 do Ridge), os modelos lineares tiveram melhor CV (Ridge 0,244 vs 0,346 do PhyResidual para T$_{ref}$; OLS 0,196 vs 0,236 do PhyResidual para T$_{alim}$), indicando maior capacidade de extrapolação.
    \end{Item}
    \end{column}
  \end{columns}
  \note{Inconsistência: modelo otimizado p/ X não foi o melhor p/ X — exceto Flux. PhyResidual: corretor de viés bem-sucedido no Flux e T\_ref. T\_alim: única exceção (0D R² -0,404). Temperaturas: contraste Test vs CV. [~2 min]}
\end{slide}
